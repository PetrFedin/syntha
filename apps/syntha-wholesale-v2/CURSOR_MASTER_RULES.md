# Cursor Master Rules — Syntha Wholesale V2

Этот файл обязателен для любой работы Cursor в `apps/syntha-wholesale-v2`.

## 1. Продуктовый канон

- Пользовательские роли только две: `brand` и `shop`.
- Ядро продукта: showroom + buying + order writing + DealSpace.
- Production/PLM/QC/Supply Chain не входят в MVP.
- Любая функция должна усиливать путь `Campaign → Collection → Showroom → Selection
