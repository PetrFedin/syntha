# 01 — Master Capability Map

## 1. Назначение

Этот документ — индекс канонического каталога функций Syntha Wholesale V2.

Каждая возможность получает постоянный `Capability ID` и связывается с:

```text
Capability ID
→ Product area
→ User job
→ Role
→ Screen ID / route
→ Domain entity
→ Permission and scope
→ Workflow ID
→ Query / command
→ Domain event
→ Priority / release
